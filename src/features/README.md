# 功能目录

业务组件放在所属功能的 `components/` 中，页面级数据加载与联动状态放在该功能的 `hooks/` 中，测试与被测模块就近存放。

- `marketing`：首页演示与动效。
- `test-cases`：用例编辑、删除和平台矩阵运行配置。
- `workspace`：组合用例与执行记录列表、筛选、统计和弹窗，管理列表数据的实时刷新。
- `runs`：执行详情、回放、步骤证据、日志、计划画板与录制编辑。

`src/app` 负责路由入口；`src/components` 保留跨功能复用的基础 UI、应用外壳和共享组件。功能可以通过明确的组件路径组合其他功能，但共享组件不依赖业务功能。

通用请求、SSE 和轮询机制在 `src/client`；浏览器与服务端共用的领域类型和纯函数在 `src/workspace`。功能目录通过 API 调用服务端，不能直接导入数据库、服务端运行时或模型实现，此边界由 ESLint 检查。

运行详情的播放状态仍由页面实例持有，通过 `useRunPlayback` 集中更新；数据订阅由 `useRunData` 管理。计划画板和录制编辑器保持动态加载，录制编辑器在首次打开后保留挂载，以保留未保存的草稿。
