# 登录身份复用

在用例 Settings 的“登录身份”中选择已有身份，或直接新建。选择“不使用登录身份”会从空白浏览器会话开始，适合验证登录、退出或未登录访问。身份管理位于“设置 → 登录身份”，也可直接访问 `/settings#login-identities`。

## 创建与验证

创建分为三个步骤：

1. **登录流程**：填写身份名称和网站，选择该网站已有流程，或进入画板新建。画板中以表单配置账号、密码以及其他普通或敏感输入，在步骤编辑和描述生成中点击“插入账号”“插入密码”使用。页面显示可读标签，不需要手写变量或 JSON。输入名称必须唯一。保存并返回后进入账号密码步骤；取消并返回不会保存画板修改。
2. **账号密码**：填写流程需要的实际值。敏感输入加密保存；编辑时留空保留已保存密码，填写新值替换。不同身份可以复用同一流程并填写不同账号。切换流程或修改输入定义时，只保留名称标识和类型一致的值；失效输入会移除。进入画板前未保存的密码会清除，返回后需重新填写。
3. **成功检查**：填写同一网站的登录后页面，以及只有登录后才会出现的文字，例如“退出登录”。缓存有效期放在高级设置，默认 60 分钟。

点击“保存并验证”会先保存配置，再向执行队列提交登录验证。也可以“仅保存”，稍后从管理页验证；使用尚未验证的身份执行用例时会自动准备登录。保存成功但验证提交失败时，点击“重试验证”只提交验证，不重复创建身份。

管理页显示尚未验证、验证排队或执行中、可复用、需要重新登录和验证失败，以及最近验证时间、关联用例和失败原因。可查看验证执行、编辑配置、重新验证、清除登录态或确认删除。验证期间不能编辑、清除或删除；仍被用例引用或有活动执行的身份不能删除。被引用的登录流程不能删除或改为其他网站、原生平台、循环身份引用。

用例设置中的身份选项显示验证状态，且仅提供当前网站的身份。登录准备在执行详情中独立展示；失败时业务步骤不会开始，可以修正对应身份、查看失败信息并重新提交验证。登录准备操作不混入业务录制步骤；需要单独调试完整登录流程时，可作为普通用例运行并使用原有高级输入配置。

## 运行与缓存

每次执行先检查身份和用例网站是否匹配，再用独立临时 context 验证缓存。有效时以登录态快照创建新的业务 context。无缓存、超过有效期或成功标志未出现时，最多执行一次登录流程并重新检查成功标志。业务执行中的 Cookie、退出登录及其他状态变化不会写回共享缓存，也不会在业务步骤中途重启用例。

缓存保存 Cookie、localStorage 和 IndexedDB，使用现有集成密钥加密。身份归属、配置版本、登录流程更新时间、浏览器提供方、浏览器类型和设备设置共同区分缓存。状态不进入 API、执行环境快照、报告或普通附件；登录准备过程不录像、不采集 trace。使用登录身份的业务执行保留录像，但关闭可能包含认证请求头的 trace。现有敏感输入保护仍适用。

多个 worker 刷新同一缓存时通过数据库租约串行，等待者拿到锁后再次检查缓存，避免重复登录；取消会关闭临时 context 并释放锁。更新身份和清除登录态会使旧刷新结果失效。有效期默认 60 分钟，每次业务执行仍验证服务端登录状态。

此版本仅支持 Web。依赖 sessionStorage 的登录、验证码或人工 MFA 暂不提供自动复用。独立 context 不隔离服务端账号数据；修改同一账号数据或限制单一有效会话的网站，应串行执行相应测试，后续可扩展账号池。

## 接口与配置边界

部署迁移和共享加密密钥统一按 [部署指南](deployment.md) 配置；用户账号密码在页面维护，登录身份表单不要求用户配置环境变量。原有目标输入的环境变量引用保持兼容。

- `GET /api/login-identities`：当前用户的身份、关联用例和可选登录流程。
- `POST /api/login-identities`、`PATCH /api/login-identities/:id`：保存身份；编辑携带 `version`，冲突返回 409。通过 `secrets: { password: "..." }` 提交敏感输入，字段名须对应所选流程定义的敏感输入；所有流程输入均须提交，名称和类型由流程决定；省略表示保留已保存密码。响应返回身份状态、关联用例及 `configuredSecrets` 字段名，不返回密码或密文。校验失败返回 `fieldErrors`，按配置字段或 `inputs.<key>` 定位问题。输入定义可包含用于页面展示的可选 `label`；运行时仍按稳定的输入键解析引用。
- `POST /api/login-identities/:id/verify`：幂等提交验证，返回 `{ runId }`；已有活动验证时复用该执行。
- `DELETE /api/login-identities/:id/cache`：清除登录态。
- `DELETE /api/login-identities/:id`：删除未被引用且无活动执行的身份。

Web target 的 `loginIdentityId` 为可选字段。不设置该字段时行为保持空白会话。记录只保留引用及非敏感的准备结果；重放使用当前登录配置准备会话，然后重放业务步骤。独立的身份验证执行需要从身份管理页重新发起，不能当作业务录制重放。
