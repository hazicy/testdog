## 应保留的结构

- 用例、执行和录制版本中的目标、计划、步骤快照具有不同生命周期。删除或修改用例不应改变历史执行；回放源被删除后也需要保留回放输入。
- 身份认证的四张表由 Better Auth 使用，应保留适配器要求的字段。
- 日志、步骤、附件和模型调用分别具有不同写入频率和查询方式；合并成执行表中的大 JSON 会增加行更新及读取成本。
- worker、资源租约、fencing token 用于防止旧 worker 写入，不应为减少字段而删掉。
- 业务 `userId` 可空目前表示未分配的本地历史数据；改为非空前必须明确迁移归属，不能随意赋给某个用户。
- 现有所有者联合索引支持隔离与分页，全局索引是否多余需要结合后台查询和实际执行计划判断。
