# 用例目录与批量运行

「测试用例」是同一个工作台：左侧目录树负责定位和组织，右侧显示当前目录的用例列表或用例画板。目录树在列表、画板和批量执行页面之间保留，展开状态不会因切换内容而重置。不提供独立的测试套件导航、文件夹详情页或用例预览页。

每个文件夹就是一个可运行的套件。根目录展示未归类用例；每个用例只有一个所属目录。目录顶部的「+」提供新建用例、新建文件夹，默认创建到当前选中的目录。文件夹菜单提供新建用例、新建子文件夹、重命名、移动、运行和删除。

新建文件夹和重命名在树内完成：Enter 保存，Esc 取消；失焦时非空保存，空白取消。中文输入法选词时 Enter 不提交。失败保留输入，可继续修改和重试。移动使用目录栏内的目标选择器，不允许移入自身、后代或其他工作区。

点击文件夹时，右侧复用现有用例列表的搜索、状态筛选和运行操作，不重复显示子目录。点击用例直接进入现有画板，切换用例时将未保存的草稿留在当前标签页，返回用例可继续编辑。保存已有用例后保持画板打开；新用例的首次保存与目录归属在同一事务中完成。

运行文件夹时包含所有子文件夹的用例。服务端在一个事务内创建整批运行快照，复用当前用例的目标、描述及计划。现有 worker 按资源调度，可以并行执行，不承诺目录顺序或串行执行。提交支持幂等重试，任一用例无法创建运行时整批回滚。

批次页面显示进度和各用例状态；各用例结果进入现有「执行记录」。停止整批执行会立即取消排队任务，并向正在执行的任务发送停止请求，已结束的结果保持不变。

删除文件夹会删除子文件夹，保留用例并将其移至根目录；历史执行保持不变。删除用例时自动清理目录关联。空目录不能运行。

目录和批次按个人／团队工作区隔离。目录名称和父目录编辑使用版本校验；用例归属保存在 `test_cases.folderId` 外键上，`folderPosition` 保留目录内顺序。移动和运行快照在工作区内使用事务锁，防止循环目录或并发写入冲突。目录树读取使用一致的事务快照，并在内存中一次归组、逐层汇总数量。

前端目录数据与实时刷新放在 `useFolderTree`，树渲染放在 `DirectoryTree`，内联编辑放在 `InlineName`。目录命令和工作台布局保留在 `SuiteExplorer`；互斥的新增、重命名、移动和删除由同一个动作状态管理。后端目录 CRUD 与批量运行分别放在 `repository.ts` 和 `runs.ts`，共用少量目录事务函数。用例重命名通过只修改名称的接口完成，不回写旧的步骤或配置。
